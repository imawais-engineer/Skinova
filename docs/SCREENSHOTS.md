# Screenshot checklist

Store submission screenshots in `public/screenshots/`. Use PNG format at desktop width (1280px or wider). Do not include private user data or API secrets.

Production URL for captures: **https://skinova-ai.vercel.app**

## Required captures

| # | Screen | Suggested filename | Status |
| --- | --- | --- | --- |
| 1 | Landing page (hero + value prop) | `project-cover.png` | Done |
| 2 | Sign up or login | `signup.png` | Capture before Devpost |
| 3 | Dashboard | `dashboard.png` | Capture before Devpost |
| 4 | Skin Scan — completed scan / stepper | `scan-complete.png` | Capture before Devpost |
| 5 | Results | `results.png` | Capture before Devpost |
| 6 | Routine | `routine.png` | Capture before Devpost |
| 7 | Skin Coach (one answered question) | `coach.png` | Capture before Devpost |
| 8 | Progress | `progress.png` | Capture before Devpost |
| 9 | Landing **Live status** section | `landing-live-status.png` | Capture before Devpost |

## How to capture

1. Use a clean test account (not production user PII).
2. Run a scan with a bundled sample (`Try one of these`) for consistent results.
3. Crop to the main content; avoid browser chrome with personal bookmarks.
4. Commit new files to `public/screenshots/` before Devpost submission.
